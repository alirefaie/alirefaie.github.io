The problem

An academic performance dataset had the usual real-world problems: inconsistent entries, values that needed verification, and records that did not quite line up. Before any analysis, the data needed to earn trust, and the cleaning itself needed to be reviewable by someone other than the person who did it.

The data

Academic records, delivered as a working file with data quality issues typical of hand-maintained spreadsheets.

Methodology

  • Profiled the dataset first: where the errors were, what kind, and how frequent.
  • Cleaned the data inside a structured workbook where each step is its own documented stage, not a silent overwrite.
  • Logged every cleaning decision: what was changed, why, and what rule justified it.
  • Added validation checks so a reviewer can confirm the final numbers against the rules applied.

Results

The deliverable is the trail itself: a Clean Data and GPA Audit workbook that reads like a lab notebook. Anyone can open it, follow each cleaning decision in order, and see exactly how the raw file became the final dataset.

The records are fully anonymized. No individual grades or identifying details appear on this site.
