# alirefaie.github.io

Source code for my data analysis and biostatistics portfolio.

**Live site: https://alirefaie.github.io**

The site presents selected real-world projects: survey design and analysis, statistical modeling, biostatistics case studies, and documented data-cleaning work. Identifying details are anonymized throughout.

## Tech

- Hand-written HTML and CSS (no frameworks, no build step)
- Hosted on GitHub Pages, served from the `main` branch root

## Structure

- `index.html` — home page with the case study cards
- `styles.css` — shared stylesheet
- One page per case study: `digital-health-literacy.html`, `digital-transformation.html`, `pecs-2017.html`, `diabetes-complications-survey.html`, `rights-framing-survey.html`, `gpa-audit.html`
